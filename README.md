# Agenda_Medica

Aplicacion web en Java para que un medico registre pacientes y agende citas.

## Tecnologias

- Java 21
- Java EE 8 Web (Servlets / JSP)
- Apache Tomcat 9
- MySQL
- NetBeans 24 (proyecto Ant)

## Como ejecutarlo

1. Ejecutar `sql/agenda_medica.sql` en MySQL para crear la base de datos.
2. Abrir el proyecto en NetBeans y configurar Tomcat 9 como servidor.
3. Ejecutar el proyecto y entrar a `http://localhost:8080/Agenda_Medica`.
